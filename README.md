# معركة الفضاء

لعبة HTML عربية تعمل مباشرة في المتصفح، وتدعم الهاتف والكمبيوتر.

## التشغيل

افتح ملف `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع.

## المحتوى

- تحريك السفينة بالسحب أو لوحة المفاتيح
- إطلاق نار تلقائي
- مراحل وأعداء وزعماء
- متجر وترقيات وسفن متعددة
- حفظ التقدم محليًا داخل المتصفح
- قنبلة النوفا والمكافآت

جميع صور اللعبة مضمّنة داخل `index.html`، لذلك لا يحتاج المشروع إلى مجلد أصول منفصل.
